ApplyPilot settings

Connect this extension's dashboard and popup to your local ApplyPilot backend.

Default http://127.0.0.1:8765 — the address applypilot run listens on.
The token is printed by applypilot setup and stored in the repository's .env file as APPLYPILOT_TOKEN.

Getting started

  1. Run applypilot setup once; it generates the token and writes it to .env.
  2. Start the backend with applypilot run.
  3. Paste the token above, press Test connection, then Save.
